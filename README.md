## 🧠 What I'm working on

More and more of my work applies **Generative AI, machine learning, RAG and agentic AI** to software engineering and quality:

- 🤖 **Autonomous testing**: AI systems that understand requirements, then generate and execute tests
- 🎯 **Intelligent regression selection**: running the tests that matter for each change
- 🩹 **Self-healing automation**: test suites that adapt as the application changes
- 📈 **Predictive quality analytics**: learning from operational signals to anticipate risk
- 🚦 **AI-assisted release decisions**: data-informed go/no-go with human oversight

## 🎯 My goal

I want to help Quality Engineering grow from a **reactive testing function** into an **adaptive, intelligence-driven capability**. In that model, AI systems understand requirements, generate and execute tests, evaluate outcomes, learn from operational signals and keep improving software quality, with appropriate human oversight.
